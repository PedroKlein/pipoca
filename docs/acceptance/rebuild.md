# Rebuild acceptance list

Every feature the clean rebuild ([ADR 0068](../adr/0068-clean-rebuild.md)) must keep, grouped by domain, with the ADRs that define it and its status before the rebuild. A slice is done when the features it touches still work. "Not built" and "Partial" items stay as they are: the rebuild adds no features.

Status: **Built**, **Partial** (part of the ADR is in code), **Not built**, **Deferred** (the ADR says later).
